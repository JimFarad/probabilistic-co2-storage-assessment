# Monte Carlo Simulation for Probabilistic CO₂ Storage Capacity Assessment

## Overview

This repository contains the Python code developed for a Master's thesis investigating **probabilistic CO₂ storage capacity assessment** in a multi-closure geological storage system.

The workflow uses a **Monte Carlo simulation approach** to quantify uncertainty in estimated CO₂ storage capacity. Starting from deterministic closure volumes derived from reservoir characterization studies, uncertainty is propagated through key petrophysical parameters, specifically **porosity** and **CO₂ saturation**.

The resulting probability distribution provides a quantitative assessment of storage capacity uncertainty and enables calculation of standard probabilistic metrics such as **P10**, **P50**, and **P90** storage estimates.

This repository accompanies the associated Master's thesis and is intended to support transparency, reproducibility, and future research in carbon capture and storage (CCS) assessment.

---

## Features

- Monte Carlo simulation framework for uncertainty quantification
- Porosity uncertainty represented using bounded probability distributions
- CO₂ saturation uncertainty represented using bounded probability distributions
- Closure-level and field-scale storage calculations
- Probabilistic storage estimates (P10, P50, P90)
- Mean and standard deviation of storage capacity
- Closure contribution analysis
- Histogram-based visualization of storage distributions
- Reproducible simulations through a fixed random seed

## Usage

Run the main simulation script from the repository root:

```bash
python monte_carlo_storage.py
```

A simplified version of the methodology used in the thesis appendix can be executed with:

```bash
python appendix_code/thesis_appendix_script.py
```

The script performs the complete Monte Carlo workflow, including:

1. Generation of random porosity realizations
2. Generation of random CO₂ saturation realizations
3. Scaling of deterministic closure volumes
4. Conversion of pore volume to stored CO₂ mass
5. Calculation of probabilistic storage statistics
6. Generation of graphical outputs

## Methodology

### Deterministic Reference Case

The starting point is a deterministic reservoir model containing estimated storage volumes for individual structural closures. These closure volumes represent the reference storage case.

### Uncertainty Sampling

Uncertainty is introduced through Monte Carlo sampling of:

- Porosity (ϕ)
- CO₂ saturation (S<sub>CO₂</sub>)

Both parameters are sampled from bounded normal distributions to ensure physically realistic values.

### Scaling Factor

For each simulation realization, a scaling factor is calculated relative to the deterministic reference case:

\[
\text{Scaling Factor}
=
\left(
\frac{\phi_{sample}}{\phi_{base}}
\right)
\times
\left(
\frac{S_{CO_2,sample}}{S_{CO_2,base}}
\right)
\]

The deterministic closure volumes are multiplied by this factor to account for petrophysical uncertainty.

### Conversion to CO₂ Mass

Scaled storage volumes are converted to stored CO₂ mass using a constant CO₂ density:

\[
M_{CO_2}
=
V_{scaled}
\times
\rho_{CO_2}
\]

where:

- \(M_{CO_2}\) = stored CO₂ mass
- \(V_{scaled}\) = scaled storage volume
- \(\rho_{CO_2}\) = CO₂ density

### Probabilistic Statistics

The resulting distribution of total storage capacity is summarized using:

- **P10** – optimistic (high-capacity) estimate
- **P50** – median estimate
- **P90** – conservative (low-capacity) estimate
- Mean storage capacity
- Standard deviation

These statistics provide a quantitative description of storage uncertainty.

## Outputs

The simulation generates numerical and graphical outputs describing the probabilistic storage capacity of the reservoir system.

Typical outputs include:

### Storage Statistics

- P10 storage capacity
- P50 storage capacity
- P90 storage capacity
- Mean storage capacity
- Standard deviation

### Closure-Level Results

- Median storage estimate for each closure
- Relative contribution of each closure to total storage capacity
- Identification of the dominant storage structure

### Figures

#### Histogram of Total Storage Capacity

Displays the probability distribution of simulated storage outcomes and highlights the P10, P50, and P90 values.

#### Closure Contribution Figure

Illustrates the relative contribution of individual structural closures to the total estimated storage capacity.

Example outputs are provided in the `example_results/` directory.
